# 跨境班列箱位与异常处置

协调中欧班列箱位、换装、单证、查验和目的站交接。

## 参与方与事实

主要参与方包括班列运营方、货代、货主、铁路承运人、口岸查验人员。领域资料记录以下已经确认的事实：

- 江西南昌开行直达比什凯克的中欧（亚）班列
- 国际班列涉及多货主装载和跨境接驳
- 跨境运输需要同步处理单证、换装和目的站交付

## 业务约束

- 箱位冻结
- 区段版本
- 单证有效性
- 危险属性
- 异常隔离
- 交接责任

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/freight_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
